## 🚀 Projeto em destaque

### 🖥️ TechCare API

Sistema de gerenciamento para assistência técnica de computadores e notebooks.

O projeto tem como objetivo simular uma aplicação real de backend, permitindo o gerenciamento de:

* 👤 Clientes
* 💻 Equipamentos
* 🔧 Ordens de serviço
* 📦 Estoque
* 💰 Orçamentos
* 🔐 Autenticação e permissões
* 📋 Histórico de serviços

### Tecnologias

```text
Python
FastAPI
PostgreSQL
SQLAlchemy
Alembic
Pytest
Docker
```

### Conceitos aplicados

O projeto está sendo desenvolvido buscando aplicar boas práticas de desenvolvimento:

* **SOLID** — separação de responsabilidades e baixo acoplamento
* **DRY** — redução de duplicação de código
* **KISS** — soluções simples e objetivas
* **YAGNI** — implementação apenas do que é necessário
* **Clean Code**
* **Testes automatizados**
* **API REST**
* **Arquitetura em camadas**

### Arquitetura

```text
API / Routes
     ↓
  Services
     ↓
Repositories
     ↓
  Database
```
